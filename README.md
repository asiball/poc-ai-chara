# poc-ai-chara

Claude Code / Codex のようなコーディング Agent を、ターミナルではなく
**ノベルゲーム風のキャラクター UI から使う、自分用のクライアント**の PoC です。

やりたいことは 3 つだけです。

1. **ACP(Agent Client Protocol)経由で Agent を動かす**。サブスクリプションのまま使えること
2. **Live2D ではなく、立ち絵(PNG)の差分と軽いアニメーションで動かす**
3. **可能なら、キャラに寄せた口調程度のロールプレイをさせる**

現時点では **調査・設計フェーズ**で、実装はまだありません。

## 1. 3 つの目的に対する現時点の答え

### 1.1 ACP でサブスクのまま Agent を動かせるか

**技術的には動く。公式に「自作クライアントで OK」と書かれた文書は無い。**

- ACP は「アプリが Agent を子プロセスとして起動し、stdio で会話する」方式。別ターミナルで動いている Claude Code に横から繋ぐものではない
- Claude Code 用アダプタ `@agentclientprotocol/claude-agent-acp` は、認証方法として `claude auth login --claudeai`(サブスク)を返す。Zed や JetBrains はこの経路で動いている
- Anthropic は 2026-06-16 に「ACP、Agent SDK、それを使った第三者アプリはサブスクで従来通り動く」と告知した。ただし課金変更は「延期中、再変更あり」
- 法務ページが禁止しているのは「第三者開発者が自分のアプリに claude.ai ログインを提供する、ユーザーに代わって資格情報を仲介する」こと。配布製品向けの文言で、自分用に無改変の `claude` バイナリのログインを使う形は Zed と同じ構図。**ただし個人自作クライアントを明示的に許可した文言は見つかっていない**
- Codex(`@agentclientprotocol/codex-acp`)は ChatGPT ログインで動き、OpenAI は第三者ハーネスでのサブスク利用を CEO が公言している。こちらも明文の規約は未確認

→ 設計上は「アプリはトークンに一切触れず、Agent 自身のログインフローに委ねる」を守る。これは自分用でもコストがかからない。

### 1.2 立ち絵を動かせるか

**PNG 差分 + CSS で十分。Live2D は不要。**

- 表情差分の切り替え(Agent の状態から機械的に決める。LLM に感情判定はさせない)
- 瞬き(目閉じ差分を数秒おきに一瞬重ねる)
- 口パク(口開き差分を、台詞のタイプライター表示中だけ交互に出す)
- 呼吸・登場の揺れ(CSS transform)

素材は `normal / thinking / happy` に「目閉じ」「口開き」を足した 5 枚程度で足りる。

### 1.3 口調のロールプレイをさせられるか

**できる。アプリが system prompt を丸ごと差し替える方式は避ける。**

- Claude Code: **output style** を使う。`.claude/output-styles/<name>.md` に口調の指示を書き、frontmatter で `keep-coding-instructions: true` にすると、コーディングの指示を保ったまま文体だけ変わる。`.claude/settings.local.json` の `outputStyle` で選ぶ。ACP アダプタは設定ソース(user / project / local)をそのまま読むので、この設定は ACP 経由でも効く見込み(**実機で要確認**)
- Claude Code(アプリ側から): アダプタは `session/new` の `_meta.systemPrompt.append` を受け付け、既定の system prompt に追記できる(ソースで確認)。output style を触りたくない場合の代替
- Codex: `AGENTS.md` に書く
- いずれも「一人称・語尾・呼び方」程度に留める。人格を強く指示するほどコード品質への影響が増える

## 2. 想定 UI

```
+--------------------------------------------------------------+
|                                                              |
|                       [立ち絵: thinking]                     |
|                                                              |
+--------------------------------------------------------------+
| ミオ                                          ● 実行中 (Bash) |
|                                                              |
| 「テストを走らせてみるね。ちょっと待ってて……」              ▼ |
|                                                              |
|   ▶ 許可する                                                 |
|     やめておく                            [変更内容を見る]   |
+--------------------------------------------------------------+
| > メッセージを入力                                    [送信] |
+--------------------------------------------------------------+
```

- 台詞ウィンドウには Agent の応答のうち **段落だけ**を出す。コードブロックや diff は右側の「ログ」パネルに出し、台詞側には「[コードを見る]」のリンクだけ残す
- permission 要求は **選択肢**として出す(ACP が返す options をそのまま並べる)
- 立ち絵は Agent の状態(待機 / 思考 / ツール実行 / 承認待ち / 完了 / エラー)で切り替える

演出とコードレビューの実用性が両立しないときは、実用を優先する(ログパネルを正とし、台詞は要約)。

## 3. MVP

「表情差分 3 枚で Claude Code と会話できる」まで。詳細は [docs/mvp.md](docs/mvp.md)。

1. **接続確認スクリプト**(Node、UI なし)で、自分の環境でサブスクログインのまま ACP が通るか確かめる
2. ブラウザ UI(Vite)+ ローカル Node で、台詞表示・表情切替・permission 選択肢・ログパネル
3. 瞬き・口パク、口調の設定

技術は **Node + TypeScript + ブラウザ UI** から始める。Tauri / Electron で包むのは「デスクトップアプリの見た目」が欲しくなってからでよい(UI と接続コードはそのまま使える)。

MVP から外すもの: Live2D、TTS、音声入力、複数 Agent 同時実行、LLM による感情判定、セッション履歴 UI、配布。

## 5. 注意

- **サブスクリプションでの利用可否は各サービスの規約に依存し、変更され得る。** 本プロジェクトはトークンを保存・仲介せず、無改変の Agent バイナリ自身のログインに委ねる。API キーでも動くようにしておく
- ACP アダプタは Anthropic / OpenAI の公式ではなく、agentclientprotocol organization(Zed / JetBrains)が保守している。バージョンを固定して使う
- キャラクター素材は自分のものを置く(リポジトリには含めない)
